## Overview

The Rust backend exposes two API surface areas:

1. **Public API** (`/api/v1/*`) — Authenticationenticated endpoints for gamification features
2. **Internal API** (`/api/internal/*`) — Java synchronization endpoints with API key auth

## Authentication

| Endpoint | Auth Type | Token Source |
|----------|-----------|--------------|
| `/api/v1/*` | Bearer (JWT) | `Authorization: Bearer <token>` |
| `/api/internal/*` | API Key | `X-API-Key: <secret>` |
| gRPC | mTLS (optional) | Certificate auth |

## Response Format

Consistent wrapper across all endpoints:

```json
{
  "success": true,
  "message": "Operation completed",
  "data": {}
}
```

Error responses:

```json
{
  "success": false,
  "message": "Invalid API key",
  "data": null
}
```

## Rate Limiting

- Public API: 100 requests/minute per user
- Internal API: 500 requests/minute per API key

Available at: `http://localhost:8081/api-docs/openapi.json`
