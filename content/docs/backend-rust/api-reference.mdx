## Gambaran Umum

Backend Rust menyediakan dua area permukaan API:

1. **Public API** (`/api/v1/*`) — Endpoint terotentikasi untuk fitur gamifikasi
2. **Internal API** (`/api/internal/*`) — Endpoint sinkronisasi Java dengan otentikasi API key

## Autentikasi

| Endpoint | Jenis Auth | Sumber Token |
|----------|-----------|--------------|
| `/api/v1/*` | Bearer (JWT) | `Authorization: Bearer <token>` |
| `/api/internal/*` | API Key | `X-API-Key: <secret>` |
| gRPC | mTLS (opsional) | Auth sertifikat |

## Format Respons

Wrapper konsisten di semua endpoint:

```json
{
  "success": true,
  "message": "Operation completed",
  "data": {}
}
```

Respons error:

```json
{
  "success": false,
  "message": "Invalid API key",
  "data": null
}
```

## Rate Limiting

- Public API: 100 request/menit per pengguna
- Internal API: 500 request/menit per API key

## Spesifikasi OpenAPI

Tersedia di: `http://localhost:8081/api-docs/openapi.json`
