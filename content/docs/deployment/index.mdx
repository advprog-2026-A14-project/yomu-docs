Platform Yomu dideploy pada satu **Google Cloud Compute Engine (VPS)** dengan arsitektur **Docker Compose** yang memisahkan layanan berdasarkan lingkungannya.

## Target Deployment

| Komponen | Detail |
|----------|--------|
| **Cloud Provider** | Google Cloud Platform (GCP) |
| **Compute** | Compute Engine VM (VPS) — Ubuntu LTS |
| **Domain** | `yomu.my.id` |
| **Orchestration** | Docker Compose v2 |
| **Reverse Proxy** | Traefik v3.1 |
| **Container Registry** | GitHub Container Registry (GHCR) |

## Arsitektur Deployment

```mermaid
flowchart TB
    User(("Pengguna"))
    DNS["Cloudflare DNS<br/>yomu.my.id"]

    subgraph GCP["Google Cloud Compute Engine"]
        subgraph Docker["Docker Host"]
            subgraph Shared["Shared Infrastructure"]
                Traefik["Traefik<br/>Reverse Proxy"]
                PG[("PostgreSQL")]
                Redis[("Redis")]
                Prom["Prometheus"]
                Graf["Grafana"]
                Loki["Loki"]
                Tempo["Tempo"]
                OTel["OTEL Collector"]
            end

            subgraph Prod["Production — Blue/Green"]
                Blue["🔵 Blue"]
                Green["🟢 Green"]
            end

            subgraph Staging["Staging"]
                ST["frontend-staging<br/>java-staging<br/>rust-staging"]
            end
        end
    end

    User --> DNS
    DNS --> Traefik
    Traefik -->|Production| Blue
    Traefik -->|Production| Green
    Traefik -->|staging.yomu.my.id| ST

    Blue --> PG & Redis
    Green --> PG & Redis
    ST --> PG & Redis

    Blue -.-> OTel
    Green -.-> OTel
    ST -.-> OTel
    OTel --> Prom & Loki & Tempo
```

## Lingkungan

| Lingkungan | Domain | Strategi | Database |
|------------|--------|----------|----------|
| **Production** | `yomu.my.id` | Blue-Green (satu aktif) | `yomu_db`, `yomu_engine` |
| **Staging** | `staging.yomu.my.id` | Always-on | `yomu_db_staging`, `yomu_engine_staging` |
